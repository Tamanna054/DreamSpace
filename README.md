# 🏠 DreamSpace

DreamSpace is a responsive interior design website where users can explore home design ideas, compare designs, plan a budget and save their favourites.

## 🔗 Live Demo
https://tamanna054.github.io/DreamSpace/

## ✨ Pages & Features
- *Home*: hero section and popular designs
- *Explore Designs*: living room, bedroom, kitchen and bathroom ideas
- *Budget Calculator*: estimate the cost of a home makeover
- *Before & After Gallery*: transformation showcase
- *Compare Designs*: compare different design options
- *My Dream Board*: save favourite designs
- *About Us* and *Contact* pages

## 🛠️ Tech Used
- HTML5
- CSS3
- JavaScript
